# 가챠 포지 퀘스트 확장 (Gacha Forge Quest Extension)

**버전:** v0.1.0 — 수동 기록 베타
가챠 포지 전용 독립 개인 확장. 공식 Gacha Forge 파일 및 한글화 확장 파일을 수정하지 않는다.

## 기능
- 가챠 포지 화면에서 `📜 퀘스트` 버튼 → 퀘스트 / 자산 / 소지품 / 기록 / 설정
- 월드 직접 등록, 전환, 분리 저장
- 일일/주간/의뢰/업적 퀘스트 직접 등록, 진행도 변경, 완료 표시
- 월드별 사용자 정의 자산 필드 및 소지품 수량 직접 편집
- 최근 변경 기록 및 JSON 백업 내보내기/가져오기

## 중요 제한
- 세계 선택은 수동. 게임 내부 세계 ID에 연결된 자동 동기화 없음.
- 퀘스트 반복 초기화, AI 의뢰 생성, 스토리 자동 분석, 전투/가챠 이벤트 자동 수집 없음.
- 게임 재화 지급 없음. 보상 텍스트는 메모에만 기록됨.
- localStorage 저장: 브라우저/도메인별이며 기기 간 자동 동기화되지 않는다.
- DOM 기반 런처 노출은 공식 1.8.12 실기기 환경에서 검증되지 않았다. 화면 판별 실패 시 런처가 표시되지 않을 수 있다.

## 설치
ZIP의 manifest.json 및 extension.js가 압축 루트에 있도록 업로드. 클라이언트 확장 실행 허용 후 가챠 포지 진입. `📜 퀘스트` 버튼 표시를 확인.

## 검증
manifest JSON 문법, JS 구문 검사, ZIP 구조 검사 수행. 실기기 실행/게임 이벤트 호환 테스트 미실시.
