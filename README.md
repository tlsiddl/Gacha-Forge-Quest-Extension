# 가챠 포지 퀘스트 확장 (Gacha Forge Quest Extension)

**버전:** v0.1.6 — 앱 내부 상단바 아이콘 / 수동 기록 베타
가챠 포지 전용 독립 개인 확장. 공식 Gacha Forge 파일 및 한글화 확장 파일을 수정하지 않는다.

## 기능
- 가챠 포지 앱 상단바 전체 화면 버튼 옆 `📜` 아이콘 → 퀘스트 / 자산 / 소지품 / 기록 / 설정
- 월드 직접 등록, 전환, 분리 저장
- 일일/주간/의뢰/업적 퀘스트 직접 등록, 진행도 변경, 완료 표시
- 월드별 사용자 정의 자산 필드 및 소지품 수량 직접 편집
- 최근 변경 기록 및 JSON 백업 내보내기/가져오기

## 중요 제한
- 세계 선택은 수동. 게임 내부 세계 ID에 연결된 자동 동기화 없음.
- 퀘스트 반복 초기화, AI 의뢰 생성, 스토리 자동 분석, 전투/가챠 이벤트 자동 수집 없음.
- 게임 재화 지급 없음. 보상 텍스트는 메모에만 기록됨.
- localStorage 저장: 브라우저/도메인별이며 기기 간 자동 동기화되지 않는다.
- 공식 1.8.12의 가챠 포지 Shadow DOM에서 `.gf-fs-bar.icon-button` 옆에 아이콘을 삽입한다. 실제 실행 테스트는 아직 하지 않았다.
- 팝업은 브라우저 최상위 레이어(dialog)에 표시하도록 설계했으며 실제 전체화면 동작은 미검증이다.

## 설치
ZIP의 manifest.json 및 extension.js가 압축 루트에 있도록 업로드. 클라이언트 확장 실행 허용 후 가챠 포지 진입. 상단바 전체 화면 버튼 옆 `📜` 아이콘 표시를 확인.

## 검증
manifest JSON 문법, JS 구문 검사, ZIP 구조 검사 수행. 실기기 실행/게임 이벤트 호환 테스트 미실시.

## 0.1.1 변경사항
- 기존 화면 구석 플로팅 버튼 대신 가챠 포지 Shadow DOM 상단바에 아이콘 삽입
- 앱 전체화면에서도 노출되도록 모달 팝업을 최상위 dialog로 변경
- 기존 localStorage 키 `gf-quest-v1` 및 데이터 구조 그대로 유지
- 사운드 확장 버튼과 별도 `data-gfq` 식별자 사용. 기존 버튼 재배치하지 않음
- 실제 가챠 포지/한글화/사운드 확장 조합 실행 검증은 아직 수행하지 않음

## 0.1.2 변경사항
- 참조 이미지의 SF 임무 화면을 반영한 다크 패널, 좌측 퀘스트·자산·소지품·기록·설정 분류, 밝은 임무 카드, 파란 강조색
- 기존 저장소 데이터/기능 유지. 게임 이벤트 자동 반영 및 스토리 프롬프트 주입은 아직 미구현
- 공식 가챠 포지의 일일·주간 활동 목표 및 업적 기능을 별도로 확인했으므로 중복 지급/진행 방지를 위한 데이터 연동 방식 추가 검증 필요
- UI 정적 수정이며 모바일/전체화면 실기기 검증 전

## 0.1.3 변경사항
- 대형 공백 위주의 설정 창을 게임 HUD형 2단 레이아웃으로 재설계
- 상단 타이틀, 왼쪽 메뉴, 중앙 퀘스트 카드, 하단 상태바 분리
- 빈 퀘스트/자산/소지품/기록 상태에 전용 안내 추가
- 모바일에서 좌측 메뉴를 수평 탭으로 전환
- 기존 데이터 키와 생성/수정/삭제 처리 유지; 자동 게임 데이터 분석 및 스토리 주입은 미구현
- JS 구문 검사 통과, 실제 게임 화면 회귀 테스트는 미실시

## 0.1.4 변경사항
- 전체화면 진입·종료 시 퀘스트 dialog를 다시 showModal 하여 최상위 레이어 복원 시도(Gacha Forge Sound 방식 참고)
- 설정에 **주입문 확인·복사** 추가. 수동 등록된 활성 퀘스트, 자산, 소지품을 스토리 문맥 텍스트로 변환해 복사함
- **자동 주입 아님**: 공식 스토리 프롬프트를 자동 변경하거나 모델 호출을 가로채지 않음. 공식 Story/Arc Directive에 직접 붙여넣는 방식으로 우선 검증
- 기존 키 `gf-quest-v1`과 데이터 구조 유지. 웹 전체화면 전환 동작 및 휴대폰/PC 실기기 검증은 미실시

## 0.1.5 변경사항
- 공식 `GET /api/gacha-forge/state`에서 활성 월드 `runId`와 이름을 읽어 자동 월드 연결 (9초 간격). 기존 동명 수동 월드는 데이터 보존한 채 연계
- `기록` 탭의 `기존 스토리 목록 조회` 버튼: 공식 `POST /api/gacha-forge/chapters` 및 `/continuity`를 읽어 기존 챕터 제목·줄거리·완료 상태·연속성 메타데이터를 로컬 확장 저장소에 보관
- 공식 게임 데이터에 **쓰기 없음**. `POST /beat`는 미생성 장면을 생성할 수 있어 조회에 사용하지 않음
- **미구현:** 과거 장면 본문 전체 수집, 장면에서 퀘스트/자산/소지품 추출 및 자동 반영, AI 자동 주입. 서버의 안전한 캐시 열람 API 또는 별도 브리지 설계 필요
- 기존 `gf-quest-v1` 키 및 수동 기능 보존; JS 구문 검사 외 실제 실행 및 다른 확장 회귀 테스트 미완료

## 0.1.6 변경사항
- 게임 월드 조회 실패 메시지를 숨기지 않고 기록 탭에 표시; `월드 연결 다시 시도` 버튼 추가
- API에서 활성 월드를 찾지 못할 때 명시적으로 진단 메시지 표시
- 퀘스트 확장 UI·알림·확인창의 사용자 안내를 존댓말로 수정
- 월드/챕터 조회 API 자체는 변경하지 않음. 사용자의 실제 HTTP 상태 코드 확인이 있어야 서버별 미연결 원인을 구체적으로 특정 가능
- 기존 저장 데이터 및 수동 기능 보존; JS 구문 검사 통과, 서버 실기기 검증 전
